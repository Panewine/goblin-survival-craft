# Goblin Survival craft

Фанатский справочник предметов и рецептов Goblin Survival v1.5.5fix15.

Сайт: https://panewine.github.io/goblin-survival-craft/

Vue 3 + Vite. Каталог содержит 471 видимый предмет, локальные иконки и шрифт. Поиск, фильтры по классу и уровню, кузницы, сеты боссов, ингредиенты, обратные связи рецептов и избранное в браузере. Сервер и внешние API не нужны.

## Локальный запуск

Node.js 22.12+:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## Публикация

Push в `main` запускает `.github/workflows/deploy.yml`: установка зависимостей, тесты, сборка и публикация `dist` на GitHub Pages. В настройках Pages выбран источник GitHub Actions. Для сборки и публикации не нужны персональные ключи или секреты; используются стандартные разрешения GitHub Actions.

В репозитории сохранены код сайта, используемые изображения, данные, конфигурация сборки, тесты и два JSON-источника для проверки каталога. Локальные скриншоты, архивы карты, инструменты извлечения, неиспользуемые стили и ресурсы, `node_modules`, `dist` и файлы с ключами исключены через `.gitignore`.
